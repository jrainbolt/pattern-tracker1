# Pattern Trainer

Pattern Trainer is a mobile-friendly React + TypeScript learning app for coding interview pattern recognition, Java-first explanations, flashcard quizzes, and scripted algorithm visualizers.


## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages

The Vite `base` is configured for:

```txt
/pattern-tracker1/
```

To deploy, build the app and publish the `dist` folder to GitHub Pages. If the repository name changes, update `homepage` in `package.json` and `base` in `vite.config.ts`.

## MVP Scope

This first version includes:

- Coding pattern lessons
- Local progress tracking
- Flashcard-style quizzes
- Java-first algorithm visualizers
- Future-facing system design trainer route

It does not include authentication, a backend, a coding sandbox, or scraped problem content.
